# CODICTS  
Design Smarter. Code Faster.

CODICTS is a UI development platform designed to help students and beginner developers build modern, real-world interfaces using reusable components, starter templates, and live code editing.

---

## Live Demo

- Website: https://codicts-website.onrender.com

---

## Project Overview

CODICTS simplifies UI development by bridging the gap between learning and practical implementation.

Instead of building interfaces from scratch, users can explore pre-built components, use structured templates, and edit code in real time to accelerate development.

---

## Key Features

- Reusable UI components for direct integration  
- Starter templates for faster project setup  
- Split-screen live code editor  
- Real-time UI preview  
- Downloadable production-ready code  
- User authentication (login and signup)  
- Save to favourites functionality  
- Pro version (mock implementation)

---

## Business Model

CODICTS follows a freemium model:

- Free version provides access to basic components and features  
- Pro version ($9/month) unlocks the full component library, templates, and downloadable production-ready code
